# Bakeerathan Karthigan — Personal Portfolio

Personal portfolio website for **Bakeerathan Karthigan**, a Computer Engineering undergraduate focused on software engineering, full-stack development, and practical systems.

## 🎯 Purpose

This repository contains the source for my personal developer portfolio, including:

- About and professional profile
- Technical skills
- Selected engineering projects
- Education and experience
- Achievements
- Contact and social links

## 🚀 Development

Install dependencies:

    npm install

Run locally:

    npm start

Build for production:

    npm run build

Deploy:

    npm run deploy
